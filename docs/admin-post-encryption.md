# 后台文章加密设置

文章编辑器支持启用加密、设置新密码和密码提示。新密码要求 6～20 位；旧文章的已有密码保持兼容，留空不会更改原密码。关闭加密会移除密码字段，文章恢复公开阅读。已有内容先备份，继续使用 Markdown frontmatter 和既有加密组件，不改变加密格式。

按用户要求，已登录管理员可在单篇文章编辑页明文查看当前密码，保存后继续回填。密码只出现在经过会话认证的单篇读取和保存响应中；文章列表与公开页面不返回密码。服务端校验输入、拒绝无密码启用加密，并沿用会话、同源校验、写入令牌、原子保存及版本冲突检查。动态模式保存后下一次访问直接生效，静态模式仍通过既有发布流程更新。

后台明确显示密码已保存的状态；密码框留空表示保留，而不是删除。受保护页面需要浏览器 Web Crypto，在公网标准 HTTP 端口访问时自动切换到 HTTPS；无法使用安全解密接口时单独提示连接问题，不再误报密码错误。

验证：开启/保留/修改/关闭密码；非法输入不改原文件；后台文章列表不包含密码；已登录单篇编辑回填密码；文章公开 HTML 不包含正文和密码；正确密码可解锁、错误密码不能解锁；后台登录密码不受影响。
